# Lights Out

Juego desarrollado en Python basado en Lights Out. El objetivo es apagar todas las lámparas del tablero mediante la selección de diferentes posiciones.

El programa cuenta con un menú principal, tres niveles de dificultad, un diseño personalizado para las lámparas, un modo de ayuda y mensajes que indican el estado de la partida. También muestra los controles necesarios para interactuar con el juego.

# Tecnologías utilizadas

Python

Consola

Módulos auxiliares para el control del teclado y la presentación del contenido

# Características

Menú principal.

Tres niveles de dificultad: fácil, medio y difícil.

Tableros de diferentes tamaños.

Diseño personalizado de las lámparas.

Modo de ayuda mediante la tecla A.

Mensajes para identificar el estado de la partida.

Controles visibles dentro de la interfaz.

# Archivos del proyecto

Carlos.py: archivo principal del juego.

comandos_consola.py: funciones auxiliares para trabajar con la consola.

controlador_teclado.py: funciones relacionadas con el control del teclado.

Los archivos auxiliares deben permanecer en el proyecto para que el programa funcione correctamente.

# Configuración e instalación

Instalar Python.

Descargar o clonar el repositorio.

Mantener los tres archivos de Python en la misma estructura de carpetas.

Abrir una terminal en la carpeta del proyecto.

Ejecutar el archivo principal con el comando:

python Carlos.py

# Recomendación

El juego está diseñado para ejecutarse en una terminal. Es necesario ajustar su tamaño para que el título, el tablero y los controles puedan mostrarse correctamente. Se recomienda reducir considerablemente el tamaño de la terminal x6.
