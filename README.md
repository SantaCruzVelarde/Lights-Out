# Lights Out

Juego desarrollado en Python basado en Lights Out. El objetivo es apagar todas las lámparas del tablero seleccionando las diferentes posiciones.

El programa cuenta con diferentes niveles de dificultad, un tablero de tamaño variable, un sistema de ayuda para resolver el tablero, mensajes sobre el estado de la partida y controles para interactuar con el juego.

**Tecnologías utilizadas**

Python

Consola

**Características**


Menú principal.

Tres niveles de dificultad: fácil, medio y difícil.

Tableros de diferentes tamaños.

Diseño personalizado para las lámparas.

Modo de ayuda (Boton A).

Mensajes de estado del juego.

Controles mostrados dentro de la interfaz.

**Configuración**

Es necesario tener Python instalado.

Asi como los archivos comandos_consola.py y controlador_teclado.py para que funcione correctamente.

Además se debe hacer la terminal 6 veces mas pequeña para que quepa perfectamente.
